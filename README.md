In ICPC contests you're allowed a small printed "team notebook" of pre-written algorithms. This repo is exactly that: a curated, ready-to-type collection of clean C++ implementations of the classic algorithms that come up in competitive programming.

## 📚 What's inside
- **Graphs** — BFS/DFS diameter, single-source shortest paths, SPFA, Floyd–Warshall, strongly connected components, and minimum spanning trees (Prim & Kruskal). See [`clean doc/Graph/`](clean%20doc/Graph).
- **Data structures** — Range Sum Query with updates and Range Minimum Query. See [`clean doc/printed/`](clean%20doc/printed).
- **Misc** — string algorithms, math helpers, bit tricks, and implementation snippets. See [`clean doc/algo_misc/`](clean%20doc/algo_misc).
- **Printable notebook** — the compiled PDF/DOCX pages actually taken into contests.

## 🎯 How to use
Each `.cpp` file is a self-contained, copy-paste-ready implementation. Grab the one you need, adapt the I/O to the problem, and go.
